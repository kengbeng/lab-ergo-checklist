# Laboratory Ergonomics Checklist

A self-contained laboratory ergonomics assessment with 30 questions across nine sections.

Open `index.html` in a modern browser. No installation or build step is required.

- Review workstation setup, working conditions and laboratory tasks.
- Record Yes / No / N/A responses and follow-up comments.
- Download and reopen editable JSON drafts.
- Download PDF assessment reports using embedded jsPDF and AutoTable libraries.
- Print an A4 assessment record with outcomes, assessor name and assessment date.

Assessment entries remain in the browser and are not submitted to a server. Download a draft to retain editable entries.

The HTML includes third-party library licence notices. The original laboratory checklist is linked within the application.

## Intended use

**For NUS internal use**

This checklist is developed for NUS staff and students to support ergonomic self-assessment and identify improvements. It does not replace a task-specific risk assessment or professional advice.

External users should obtain their institution’s approval and assess its suitability before use. References to NUS procedures, contacts and support arrangements apply only within NUS.
